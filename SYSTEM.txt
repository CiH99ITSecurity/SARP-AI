============================================================
RECOMMENDED SYSTEM REQUIREMENTS | متطلبات النظام الموصى بها
============================================================

ENGLISH
-------
Ensure that your system meets the following specifications before starting the SARP AI Pro Digital Intelligence System.

- Processor and OS: Requires a 64-bit processor and operating system.
- Operating System: Windows 10 64-bit (latest updates) or Windows 11 64-bit (latest updates).
- Processor: Intel Core i5-11XX or AMD Ryzen 5 3XXX or above.
- Memory: 16 GB RAM or above.
- DirectX: Version 12.
- Network: Broadband Internet connection.
- Storage Type: SSD.
- Available Storage: 125 GB.
- Windows Region: Arabic.
- Microsoft .NET Framework: Version 4.8.
- Microsoft Office: 2010 exclusively.

العربية
-------
تأكد من توفر المواصفات التالية في جهازك قبل تشغيل نظام سارب للذكاء الرقمي SARP AI Pro.

- المعالج ونظام التشغيل: معالج ونظام تشغيل بمعمارية 64-bit.
- نظام التشغيل: Windows 10 إصدار 64-bit مع آخر التحديثات، أو Windows 11 إصدار 64-bit مع آخر التحديثات.
- المعالج: Intel Core i5-11XX أو AMD Ryzen 5 3XXX أو أحدث.
- الذاكرة العشوائية (RAM): ‏16 GB أو أكثر.
- DirectX: الإصدار 12.
- الاتصال بالإنترنت: اتصال إنترنت واسع النطاق.
- نوع وحدة التخزين: SSD.
- المساحة التخزينية المتاحة: ‏125 GB.
- إعدادات المنطقة في Windows: اللغة العربية.
- Microsoft .NET Framework: الإصدار 4.8.
- Microsoft Office: إصدار 2010 حصريًا.
